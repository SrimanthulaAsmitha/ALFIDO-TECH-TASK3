# 📖 Project Overview

This project is a responsive Movie Search Application developed using HTML5, CSS3, and JavaScript.

The application allows users to search for movies dynamically using API integration and displays movie details such as posters, titles, ratings, and release information.

The project was developed to improve frontend development skills including API handling, responsive design, and dynamic UI updates.

---

# ✨ Features

- Responsive and modern user interface  
- Search movies dynamically using API  
- Displays movie posters and details  
- Real-time search functionality  
- Attractive card-based layout  
- Smooth user experience  
- Responsive design for desktop and mobile devices  
- API integration using Fetch  
- Clean and professional UI design  
- Hosted online using GitHub Pages
